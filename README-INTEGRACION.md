# AIProps 2.0 · QuoteFlow Pro integrado

Incluye: home existente con modal QuoteFlow que reproduce MP4, página /soluciones/quoteflow/ con funcionalidades, sectores y Calendly, y video local + poster.

## Publicación
Subir todos los archivos y carpetas a la raíz de la rama `aiprops-v2-development`. Mantener la jerarquía. No subir a `main`. No hacer Pull Request ni Merge.

## Validación
1. En Preview Vercel, abrir Demo Lab y pulsar Ver video en QuoteFlow.
2. Abrir Conocer más, verificar video y CTA de Calendly.
3. Verificar responsive móvil y enlace de retorno.
4. Comprobar que Production sigue en main.

## Nota
El MP4 pesa aproximadamente 20 MB y está alojado como archivo estático en el proyecto; para escalar decenas de videos conviene hosting de video dedicado.
