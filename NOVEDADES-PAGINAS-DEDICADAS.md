# AIProps Solutions Lab — Páginas dedicadas

Seis páginas completas en `soluciones/` con: problema que resuelven, funciones, ejemplo de flujo, reportes, industrias, personalización funcional y estética, comercial MP4 y CTA al formulario.

## Navegación

`Conocer más` -> página dedicada -> `Completar formulario de evaluación` -> `index.html?solution=<slug>#agenda`.

## Para publicar

Subir el contenido del ZIP a la rama `aiprops-v2-development` exclusivamente. Revisar Preview en Vercel; no realizar merge a `main`.

## Automatización

El backend de formularios y correo incluido se mantiene como en la versión anterior. El envío real necesita configurar credenciales del proveedor de correo y validarlo en Preview antes de lanzamiento.

## Alcance

No se promete software listo para producción ni cumplimiento fiscal/legal certificado. Los reportes son ilustrativos y el diseño de producción se cotiza después de evaluar cada negocio.
